# What I will do

**Photos**
- Rebuild every site photo in a wider set of sizes, including a 2x retina size, and let the browser pick the right one.
- Encode at higher quality, AVIF first, WebP second, so files stay small.
- Keep exact width and height on every image so nothing jumps while loading.
- Sharpen the logo so it is never soft on a laptop or phone.

**Speed**
- Only the first screen's image loads right away, everything below waits until it is scrolled near.
- Preload the one hero image on each page so the top paints immediately.
- Push non essential scripts to start after the page is usable.
- Long cache the photo files so repeat visits are instant.

**Clean transitions**
- Smooth fade and lift when moving between pages, and a gentle fade in for photos as they arrive, so nothing pops in hard.
- Motion respects the visitor's reduce motion setting.

**Savvy Swim only**
- Sweep the whole site: page titles, share previews, app manifest, icons, error text and the browser tab, so visitors only ever see Savvy Swim. The Lovable badge is already off, this confirms every remaining spot.
